# UDP Racing

Учебный проект по разработке UDP-протокола и проектированию сетевой архитектуры.

Проект представляет собой сетевую основу для 2D игры-гонки с видом сверху. Взаимодействие между клиентом и выделенным сервером осуществляется по протоколу UDP.

## Архитектура

Используется топология **Dedicated Server**.

```text
Client
   │
   │ UDP
   ▼
Dedicated Server
```

Сервер отвечает за обработку игровых команд и является центральной точкой обработки сетевых сообщений.

### Основные компоненты

* `src/client.cpp` — UDP-клиент;
* `src/server.cpp` — UDP-сервер;
* `src/packet_handler.h` — обработка полученных пакетов;
* `src/protocol.h` — описание протокола и сериализация данных.

## Поддерживаемые команды

Протокол поддерживает четыре типа пакетов:

| Значение | Тип      | Назначение                    |
| -------: | -------- | ----------------------------- |
|      `1` | MOVEMENT | Передача координат автомобиля |
|      `2` | SHOOT    | Команда использования оружия  |
|      `3` | STATE    | Передача состояния игрока     |
|      `4` | ACK      | Подтверждение команды         |

### MOVEMENT

Передаёт координаты:

* `x`
* `y`
* `z`

Размер полного UDP-пакета — **19 байт**.

### SHOOT

Передаёт идентификатор оружия `weaponId`.

Размер полного UDP-пакета — **8 байт**.

### STATE

Содержит:

* `playerId`;
* `x`;
* `y`;
* `z`.

Размер полного UDP-пакета — **21 байт**.

### ACK

Подтверждает получение команды.

Размер полного UDP-пакета — **7 байт**.

## Сериализация

Для целочисленных полей используется сетевой порядок байтов:

```cpp
htons()
ntohs()
htonl()
ntohl()
```

Координаты `float` передаются через их битовое представление `uint32_t` с последующим преобразованием порядка байтов.

Это позволяет явно определить формат данных, передаваемых по сети.

## Требования

Для сборки проекта необходимы:

* Windows;
* MSYS2 UCRT64;
* GCC с поддержкой C++17;
* библиотека Winsock2.

## Сборка

Перейдите в корневую папку проекта:

```bash
cd udp-racing
```

Соберите сервер:

```bash
g++ -std=c++17 -Wall -Wextra src/server.cpp -o server.exe -lws2_32
```

Соберите клиент:

```bash
g++ -std=c++17 -Wall -Wextra src/client.cpp -o client.exe -lws2_32
```

## Запуск

Сначала запустите сервер:

```bash
./server.exe
```

После запуска должно появиться:

```text
UDP server started on port 54000
Waiting for packets...
```

Затем в другом терминале запустите клиент:

```bash
./client.exe
```

Клиент автоматически отправляет 10 пакетов с интервалом в одну секунду.

Команды чередуются:

```text
MOVEMENT
SHOOT
MOVEMENT
SHOOT
...
```

## Пример результата

Пример ответа на MOVEMENT:

```text
Sending MOVEMENT, sequence=1
Sent 19 bytes
Received response: type=3, sequence=1, payloadSize=14
State: playerId=1, x=11, y=20, z=0
```

Пример ответа на SHOOT:

```text
Sending SHOOT, sequence=2
Sent 8 bytes
Received response: type=4, sequence=2, payloadSize=0
ACK received
```

## Ограничения текущей версии

Текущая версия является учебным прототипом.

Не реализованы:

* авторизация;
* шифрование;
* CRC32;
* повторная передача потерянных пакетов;
* защита от повторных пакетов;
* несколько игровых сессий;
* полноценная синхронизация нескольких игроков.

Эти функции могут быть добавлены в следующих версиях.

## Результат

Проект демонстрирует:

* создание UDP-сокета;
* двусторонний обмен данными;
* структуру собственного сетевого протокола;
* сериализацию и десериализацию данных;
* использование порядкового номера пакета;
* обработку игровых команд;
* передачу состояния от сервера клиенту;
* разделение ответственности между компонентами системы.
